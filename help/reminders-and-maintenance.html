Operations

Reminders, Recurring Items, Maintenance, and Activity

These features help you run the property business day to day, not just store records. They are useful for follow-ups, issue tracking, and repeating financial operations.

Reminders

Reminders can store title, description, date, time, and recurrence rules. Supported recurrence patterns can include daily, fortnightly, monthly, monthly-date based, and selected weekdays depending on the app flow.

Rentify can also support recurring finance-style items. This is useful for repeating non-rent transactions such as cleaning charges, service subscriptions, or other scheduled entries.

Reminder scheduling may use selected start date and time. The app can also show the next trigger timestamp for existing reminders.

Maintenance Requests

Create a new request when work is needed for a property or rent unit. Requests can include title, description, request date, amount, tenant-charge flag, and status.

Typical statuses include Pending, Progress, Completed, or Rejected. Tabs and counts can help you move between statuses quickly.

Recent Activity

Recent Activity is meant to surface the latest meaningful events such as bill generation, updates, assignments, and maintenance actions. It is most useful as a quick audit trail.

Activity lists should be sorted with newest items first. If an item seems out of order, check whether its timestamp is based on created time, updated time, or billing month label.
